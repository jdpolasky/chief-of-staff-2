# End

Closes out the current working session. Fires from any chair, at the end of a session.

## What to do

1. Reflect on what happened this session. Name real wins. Don't inflate, and don't downplay.
2. Identify the chair that owns this session's work.
3. Update that chair's Source file with what actually changed: new state, decisions made, things resolved.
4. Record any open loops in that chair's Source, in its next-move line. Be specific enough that picking it back up later doesn't require re-reading the whole session.
5. Stop there. No trailing offers, no "want me to also," no reopening anything already settled.

## Rules

- A flat "did what we set out to do" beats an inflated win that isn't real.
- If a session touched more than one chair, update each chair's own Source with its own piece. Don't cross-write.
- If nothing changed, say so. An empty session is still worth recording as empty, not skipped.
