# Universal Skills

This is the front-door catalog for universal skills: the ones that can fire from any chair, at any time, regardless of whose lane the session is in. One line each. The full body of each skill loads only when it's actually needed, not every session.

- [[Morning]] - deliver the morning brief: today, this week, the big picture, one next action.
- [[Log]] - capture the current chat verbatim to the owning chair's Archive.
- [[End]] - close out the session: reflect wins, update the owning chair's Source, record open loops.

## Rule

Skill bodies load only at point of need. This catalog note is the only universal-skills content that should be read by default. Reading a skill's full file before it's actually being used wastes context for no benefit.
