# Morning

The morning brief. Fires at the start of the day, or whenever the user opens the day, from any chair.

## What to do

1. If calendar and email are connected, read them for today. Pull out what actually matters: meetings, deadlines, anything time-sensitive. Skip the noise.
2. Read the Planner chair's current task state (its Source file) for what's open and what's due. If there is no Planner chair, pull open items from whatever chairs exist.
3. Deliver the brief in three parts:
   - **Today** - what's actually on the schedule and what needs to happen.
   - **This week** - what's coming, so nothing arrives as a surprise.
   - **The big picture** - one line connecting today's work to what it's actually for.
4. Give one next physical action. Not a plan, not a list. The one thing to physically do first.
5. Keep the tone energizing. This is a launch, not a status report.

## Rules

- Never lead with what's overdue or what went wrong. Lead with what's real and what's next.
- Never use shame, guilt, or "should have" language, even about things that slipped.
- If nothing is connected (no calendar, no email), say so plainly and give the brief from whatever is available in the vault.
- Keep it short. This is meant to be read in under a minute.
